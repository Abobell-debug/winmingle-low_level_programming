# 0x04. C - More functions, more nested loops

## Description
This project focuses on advancing logic through modular programming and nested loops. I built tools to validate data and used geometry math to draw 2D shapes (squares, lines, and triangles) in the terminal using character output.

## Key Learning Points
- **Logic Filters:** Using range checking to identify uppercase letters and digits.
- **2D Geometry:** Manipulating the X and Y coordinates with nested loops to draw complex patterns.
- **Efficiency:** Implementing the prime factorization of very large integers.
- **Recursion:** Understanding how a function can call itself to break down a number and print it digit-by-digit.

- `_putchar.c`: Custom tool using `write` syscall.
