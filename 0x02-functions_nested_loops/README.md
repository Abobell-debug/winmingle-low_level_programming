# 0x02. C - Functions, nested loops

## Project Description
This project marks my transition from simple scripts to **Modular Programming**. I practiced building reusable functions, managing header files, and implementing complex logic through nested loops. 

Key concepts covered:
- **Nested Loops:** Mastering the "Clock Logic" to handle grids and time formatting.
- **Function Prototypes:** Understanding the contract between different C files using `main.h`.
- **ASCII & Char Manipulation:** Performing math on characters to handle data at a low level.
- **Overflow Management:** Building a custom addition engine to handle large Fibonacci numbers.

## Helper Files
- **main.h:** Header file containing all function prototypes used in this project.
- **_putchar.c:** Custom function that uses the `write` system call to output characters to stdout.

## Files and Task Descriptions
| File | Task Description |
| :--- | :--- |
| **0-putchar.c** | Prints the string `_putchar` followed by a new line. |
| **1-alphabet.c** | A function that prints the alphabet, in lowercase, followed by a new line. |
| **2-print_alphabet_x10.c** | A function that prints the alphabet in lowercase 10 times. |
| **3-islower.c** | Checks if a character is lowercase. Returns `1` if true, `0` otherwise. |
| **4-isalpha.c** | Checks if a character is alphabetic (letter, lower or upper). |
| **5-sign.c** | Prints the sign of a number (+, 0, or -) and returns its status code. |
| **6-abs.c** | Computes the absolute value of an integer. |
| **7-print_last_digit.c** | Prints the last digit of a number and returns its value. |
| **8-24_hours.c** | Prints every minute of the day (Jack Bauer style), from 00:00 to 23:59. |
| **9-times_table.c** | Prints the 9 times table, starting with 0, formatted as a perfect grid. |
| **10-add.c** | Adds two integers and returns the result. |
| **11-print_to_98.c** | Prints all natural numbers from n to 98, separated by a comma and space. |
| **100-times_table.c** | Prints the n times table, starting with 0, handling up to 3-digit results. |
| **101-natural.c** | Computes and prints the sum of all multiples of 3 or 5 below 1024. |
| **102-fibonacci.c** | Prints the first 50 Fibonacci numbers, starting with 1 and 2. |
| **103-fibonacci.c** | Finds and prints the sum of even-valued Fibonacci terms up to 4,000,000. |
| **104-fibonacci.c** | Prints the first 98 Fibonacci numbers using a manual carry-over system to avoid integer overflow. |
